# Dynamic connectivity

`dynconn` publishes a participant's admissible cleaned runs for interactive
vertex- or voxel-level dynamic connectivity in Connectome Workbench. It does
not precompute a connectivity matrix. Workbench calculates correlations when
the user selects a location in a scene generated by `nro scene`.

## Inputs and admission

One instance selects a participant, space, and smoothing level. `input_filter`
uses the same BIDS-entity matching rules as `microparcellation`. The module
reads the clean sidecars to exclude runs with undefined cleaning, too few
retained frames, too little residual design freedom, low effective rank, or
excessive temporal concentration. It also enforces the configured minimum
usable-run count and aggregate retained-frame count.

The admitted runs must have one repetition time. Censored frames are omitted.
Each run is centered and standardized independently. The default `weighting:
precision` setting weights its covariance contribution in proportion to the
algebraic temporal rank recorded by `clean`. Set `weighting: equal` to give
every admitted run the same contribution.
The manifest records each included run's half-open `start_frame` and
`stop_frame` range, so the original run boundaries remain available. It also
records excluded runs and their reasons.

## Time-series representation

The default `low_rank: true` representation publishes a synthetic series that
encodes a rank-limited approximation of the pooled correlation matrix. It
estimates the leading spatial eigenspace of the weighted run covariances with a
streamed randomized decomposition. It does not form a
vertex-by-vertex or voxel-by-voxel matrix. Set `low_rank: false` to publish the
retained acquisition frames in their original order.

The default dimension ceiling is 1,000. If the centered input rank is below the
ceiling, the fit uses the available rank. For `D` fitted dimensions, the output
contains `D + 1` synthetic samples. Their sample covariance reconstructs the
fitted rank-`D` matrix, and their Pearson correlations reconstruct its normalized
correlation matrix. The samples use orthonormal, zero-mean Helmert contrasts.
They are coordinates for Workbench seed correlation, not acquisition times. The
manifest records the requested and fitted dimensions, fitted eigenvalues,
realized rank, retained variance, locations with zero temporal variance, and
the effective random seed.

## Public artifacts

Outputs from every space and smoothing target share
`derivatives/dynconn/LINEAGE/sub-ID/`. Their filenames include both entities.

Surface targets contain one `_desc-dynamicConnectivity_bold.dtseries.nii`
file. Its brain-model axis joins the complete left and right surface meshes;
for a full representation, its series axis records the common repetition time.
A low-rank representation uses a nominal one-second step because its series
axis is synthetic.

Volume targets contain one uncompressed
`_desc-dynamicConnectivity_bold.nii`. The uncompressed 4D NIfTI supports
random access while Workbench calculates voxelwise correlations.

Both forms include a YAML publication manifest and a JSON publication index.
Build and open a combined scene with:

```bash
nro scene -m dynconn -p PARTICIPANT -P PROJECT -s SPACE -S MM --open
```

## Configuration

`output_dir`, `prefix`, and `overwrite` control direct execution and publication.
The `inclusion` mapping contains the sidecar-based run and aggregate thresholds.
`weighting` selects equal or effective-DOF covariance pooling.
`low_rank` enables compression. When enabled, `low_rank_options.dimensions`
sets the output-rank ceiling. `oversampling` expands the trial subspace beyond
that ceiling before truncation. This reduces the chance that randomized range
finding misses components near the cutoff, at the cost of memory and matrix
multiplication proportional to the expanded subspace width. It does not add
dimensions to the published result.

`power_iterations` repeatedly applies the correlation operator to the trial
subspace. Each iteration separates stronger components from weaker ones and
improves accuracy when the spectrum decays slowly. Each iteration requires one
additional streaming pass and more matrix multiplication. The random seed comes
from the host system and is recorded in the manifest so the randomized fit can
be reproduced. It is not a shared dynconn configuration value. Low-rank options
do not affect scientific freshness while `low_rank` is false.
